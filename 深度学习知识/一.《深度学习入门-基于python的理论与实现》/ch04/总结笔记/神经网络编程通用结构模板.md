# 深度学习网络编程通用结构模板

这是所有深度学习代码（无论是手写 NumPy 还是 PyTorch）的**骨架**。以后你看到任何复杂的网络代码，直接往这个模板里套，就能瞬间看懂。

---

## 一、 网络类的解剖图 (`TwoLayerNet`)

**核心思想**：把一个网络看作一个**独立的对象**，它自包含所有的权重和计算逻辑。

### 1. 必需的属性 (Attributes)
网络必须得有“记忆”，这些记忆就是权重参数。

*   **`self.params = {}`** (字典或列表)
    *   **作用**：存放所有的 $W$ (权重) 和 $b$ (偏置)。
    *   **初始化**：在 `__init__` 中完成。通常用随机高斯分布 (`np.random.randn`) 初始化 $W$，用 0 初始化 $b$。
    *   **直觉**：这就是网络的“脑细胞”。

### 2. 必需的方法 (Methods)

一个标准的网络类，必须具备以下 4 个功能模块：

#### A. `__init__` (构造函数)
*   **输入**：输入层大小、隐藏层大小、输出层大小。
*   **动作**：初始化 `self.params`。
*   **代码套路**：
    ```python
    self.params['W1'] = 0.01 * np.random.randn(...) # 随机化打破对称
    self.params['b1'] = np.zeros(...)               # 偏置设为0
    ```

#### B. `predict(x)` (前向传播 / 推理)
*   **输入**：输入数据 `x` (图片)。
*   **输出**：预测结果 `y` (概率分布或分数)。
*   **动作**：`x` -> `Dot` -> `Sigmoid` -> `Dot` -> `Softmax` -> `y`。
*   **地位**：这是网络干活的流程。

#### C. `loss(x, t)` (损失计算 / 评价)
*   **输入**：输入数据 `x`，正确答案 `t` (Label)。
*   **输出**：一个标量 Loss 值。
*   **动作**：先调用 `y = predict(x)`，再调用 `cross_entropy(y, t)`。
*   **地位**：这是告诉网络“你现在错得有多离谱”。

#### D. `gradient(x, t)` (梯度计算 / 反思)
*   **输入**：输入数据 `x`，正确答案 `t`。
*   **输出**：一个字典 `grads`，结构和 `self.params` 一模一样（每个 W 都有对应的 dW）。
*   **动作**：
    *   **方案一 (Ch04)**：数值微分 (`numerical_gradient`)。慢，但简单。
    *   **方案二 (Ch05)**：误差反向传播。快，但代码复杂。
*   **地位**：这是告诉网络“每个参数该往哪个方向改才能变好”。

## 二、 训练循环的解剖图 (`train_neuralnet.py`)

**核心思想**：这是一个死循环，不断地给网络喂数据，然后让它更新自己。

### 标准流程 (4步走)

1.  **准备阶段 (Setup)**
    *   加载数据 (`load_mnist`)。
    *   实例化网络 (`net = TwoLayerNet(...)`)。
    *   设定超参数：`iters_num` (跑多少次), `batch_size` (一次吃多少), `lr` (学习率)。

2.  **循环阶段 (Training Loop)**
    *   **Step 1: Mini-batch (随机抽样)**
        *   从 60000 个数据里随机抓 100 个出来。
        *   `mask = np.random.choice(...)`
    *   **Step 2: Gradient (计算梯度)**
        *   **最关键的一步**。调用网络的 `gradient` 方法。
        *   `grads = net.gradient(x_batch, t_batch)`
    *   **Step 3: Update (参数更新)**
        *   拿着梯度，按照学习率去修改参数。
        *   `W -= lr * dW` (所有参数都要减)。
    *   **Step 4: Log (记录日志)**
        *   记录 Loss，记录 Accuracy。
        *   每隔一个 Epoch 打印一次，防止控制台被刷屏。

## 三、 脑图：如何使用这个类？

当你拿到一个网络类时，你的使用逻辑永远是：

1.  **实例化它**：`model = MyNet(...)`
2.  **问它怎么改**：`grads = model.gradient(x, t)`
3.  **帮它改**：`model.params -= lr * grads`

(在 PyTorch 中，步骤 2 和 3 被封装成了 `loss.backward()` 和 `optimizer.step()`，但本质逻辑完全一样)。
