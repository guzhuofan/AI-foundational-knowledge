# 视频笔记：全面解析"世界模型"——定义、路线、实践与AGI的更近一步

**来源**: [B站 BV11LPWzNEkm](https://www.bilibili.com/video/BV11LPWzNEkm/) | 硅谷101 · 约50分钟
**转录方式**: yt-dlp + Whisper tiny → 小龙虾精炼总结

---

## 一、为什么现在都在谈世界模型？

- LLM 的 Scaling Law 性价比在断崖式下降
- **Yann LeCun**：离开 Meta 回巴黎创业，放言"GPT 路线是死路"，认为 LLM 最多做个更会说话的模型
- **李飞飞**：LLM 是"黑暗中的文字巨人"——能言善辩却脱离现实
- 行业共识：AI 下一步必须**直接接触物理世界**，语言太干净，无法提供因果经验

---

## 二、世界模型三要素

| 要素 | 说明 |
|------|------|
| **感知世界** | 从原始输入提取关键结构，百万像素压缩为少量编码 |
| **预测未来** | 推演"如果我推杯子/开门/走两步，世界会怎样" |
| **规划行动** | 在内部模拟找到最优策略，再在现实中执行 |

**一句话：** 把真实世界压缩到潜在空间的模拟器，在其中做预测和决策。

---

## 三、LLM vs 世界模型

| 维度 | LLM | 世界模型 |
|------|-----|---------|
| 预测目标 | 下一个 token | 下一帧画面 / 下一次状态变化 |
| 训练数据 | 文本（静态） | 视频、传感器、动作反馈（动态） |
| 输出 | 文本/图像 | 未来状态预测 + 行动方案 |
| 学习方式 | 通过语言间接理解 | 通过交互和推演直接理解 |
| 适用场景 | 对话、写作 | 机器人、自动驾驶、物理模拟 |

> 李飞飞："One is about saying things, the other is about seeing and doing things."

两者是**互补关系**：世界模型给 LLM 补上现实世界维度。

---

## 四、三层架构（来自 Meta 嘉宾）

```
第2层：世界生成（当前最热闹）
  ├── 视频生成：把世界"画出来"
  └── 3D空间智能：把世界"建出来"
       ↓
第1层：世界模型核心（抽象）
  ├── 表示世界规则 → 预测未来 → 规划行动
       ↓
第3层：智能体训练（目的层）
  ├── 在生成的世界里训练 AI 行动
  └── 迁移到真实世界
```

Meta 的策略：因为不同垂直场景需要不同表现形式，所以**四条路线全做**——游戏（Bella Horizon Studio）、内容创作（纯视频）、3D重建（高斯泼溅）。

---

## 五、四大技术路线

### 1. 视频生成 🎬
**代表**: OpenAI Sora、Google Genie 3、Project Genny、可灵、Vidu

- 让 AI 直接生成能动起来、随时间演化的世界
- **Genie 3 突破**：不只是播放，还能**实时交互**——黑板上写字后走开回来字还在，说明"记住了世界状态"
- **优势**：结果可见、数据丰富（互联网海量视频）、Scaling 效应明显
- **死穴**：画的是皮——生成的汽车很逼真，问"长宽高？备胎在哪？"答不出。**世界理解藏在权重里，不是显式的**

### 2. 3D 空间智能 🧱
**代表**: 李飞飞 World Labs

- 不画世界，而是**建世界**——给一张图就重建完整 3D 场景
- **核心逻辑**：真实世界是 3D 的，AI 必须理解空间才能理解时间
- **优势**：显式物理结构（碰撞/遮挡/重力严格正确），天然适配物理引擎
- **融资**：11 亿美元，估值 51 亿，一年半翻 5 倍
- **死穴**：3D 数据极稀缺、几何结构难保证、算力远超 2D

### 3. 智能体训练 🎮
**代表**: Google SIMA

- 用世界生成模型当训练场，AI 在虚拟世界里不断犯错学习
- **最新**：SIMA 已开始用 **Genie 3 生成的**游戏世界训练
- **能力**：理解复杂多步指令、陌生环境自主探索、跨游戏跨环境泛化
- **关键问题**：Sim-to-Real Gap 仍是开放难题

### 4. JEPA 抽象预测 🔬
**代表**: Yann LeCun（Meta）

- **不画世界，直接学习世界的抽象结构**
- 推球例子：视频模型预测下一帧所有像素，JEPA 只关心"球往哪滚、速度怎么变、会不会撞到障碍"
- **三步结构**：Encoder（压缩为抽象表征）→ Predictor（预测抽象状态变化）→ 对齐真实未来编码
- **优势**：计算成本极低、更易捕捉因果关系、输出接近机器人需要的结构化信息
- **死穴（Why 还不是主流）**：
  - 不可见——学的一切都在抽象空间里，无从验证
  - 监督目标难设计——什么算"结构"？没有统一答案
  - 缺乏统一 Benchmark

## 六、产业冲击

| 领域 | 变化 |
|------|------|
| 🤖 **机器人** | 从"每次新任务 = 新工程项目"走向"先在脑子里模拟再行动" |
| 🚗 **自动驾驶** | Waymo 已把核心重构为世界模型——从反应式走向预判式 |
| 👓 **可穿戴设备** | 从信息终端变成"随身世界理解引擎"，理解你的环境和意图 |
| 🎮 **内容/游戏** | 从人工搭世界变成给定规则 AI 自动生成和演化 |
| 🧠 **AI Agent** | 第一次有了可大规模训练的内在世界，解决"没有训练环境"的根本瓶颈 |

---

## 七、风险

- **幻觉升级**：LLM 编造事实，世界模型**编造整个物理世界**（误判物体重量、低估碰撞后果）
- **权力集中**：极少数机构能构建和运行 → 前所未有的预测能力 → 信息垄断+社会操控
- **虚拟现实边界模糊**：深度伪造进入"超真实阶段"
- **监管地狱**：内部状态不可审计、推理过程不可见

> LeCun 的终极愿景：如果世界模型跑通到能泛化产生新科学、新数学、超越人类——那它就具备了"建立新文明的能力"。
