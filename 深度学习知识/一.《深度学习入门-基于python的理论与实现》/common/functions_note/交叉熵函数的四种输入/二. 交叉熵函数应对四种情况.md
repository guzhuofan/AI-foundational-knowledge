## 问题描述
```python
def cross_entropy_error(y, t):
    if y.ndim == 1:
        t = t.reshape(1, t.size)
        y = y.reshape(1, y.size)
        
    # 把t中每一个图片(行)的正确标签取出来, 构成一个一维向量
    if t.size == y.size:
        t = t.argmax(axis=1)
             
    batch_size = y.shape[0]
    return -np.sum(np.log(y[np.arange(batch_size), t] + 1e-7)) / batch_size
```
对于这个交叉熵函数, 我有点不确定其会有什么样的输入, 这个函数又是怎么处理各种输入的? 所以单独拿出来讨论一下这个函数的输入输出情况.

## 分类讨论输入情况
### 1. 单个数据 + Label (最简单的Case)
**输入:**
- y: [0.1, 0.8, 0.1] (shape (3,) )
- t: 1 (shape () , 标量)

**处理:**
- y.ndim == 1 触发， y 变为 (1, 3) ， t 变为 (1, 1) 
- t.size (1) != y.size (3)，跳过 One-hot 转换

**最终计算:**
- np.arange(batch_size) 是 `[0]`, t 是 `[[1]]` .
- `y[[0],[[1]]]` 广播后容器的样子为`[[x]]`, 取出y第 0 行第 1 列的概率 0.8 
- 最终返回`[[0.8]]`, 进行后续计算.

### 2. 单个数据 + One-hot (最绕的Case)
**输入:**
- y: [0.1, 0.8, 0.1] (shape (3,) )
- t: [0, 1, 0] (shape (3,) )

**处理:**
- y.ndim == 1 触发, y 变为 (1, 3), t 变为 (1, 3) 
- t.size (3) == y.size (3), 触发 One-hot 转换 
- t.argmax(axis=1), t为`[[0, 1, 0]]`, axis=1 表示聚合 shape(1, 3) 中的3对应的元素抹除这一维使得 shape 变为(1,), 也就是说 argmax 会在3对应的维度上找到最大值, 返回最大值的索引. 将 `[[0, 1, 0]]` 变为 `[1]` .
- 这时t就变为标签了.

**最终计算:**
- np.arange(batch_size) 是 `[0]`, t 是 `[1]`.
- `y[[0],[1]]` , 容器的样子为`[x]`, 取出 y 的第 0 行第 1 列的概率 0.8 
- 最终返回`[0.8]`, 进行后续计算.

### 3. 批量数据 + Label (最标准的Case)
**输入:**
- y: 2个样本，shape (2, 3) 
- t: [2, 0] (shape (2,) )

**处理:**
- y.ndim != 1, 跳过 reshape
- t.size (2) != y.size (6), 跳过 One-hot 转换

**最终计算:**
- np.arange(batch_size) 是 `[0, 1]`, t 为 `[2, 0]`, 即每个样本的正确标签.
- `y[[0, 1],[2, 0]]` , 容器的样子为`[x1, x2]`, 取出 y 的第 0 行第 2 列的概率填入 x1, 第 1 行第 0 列的概率填入 x2.
- 最终返回`[x1, x2]`后, 进行后续计算.

### 4. 批量数据 + One-hot (最通用的Case)
**输入:**
- y: 2个样本，shape (2, 3) 
- t: [[0, 0, 1], [1, 0, 0]] (shape (2, 3) )

**处理:**
- y.ndim != 1, 跳过 reshape
- t.size (6) == y.size (6), 触发 One-hot 转换
- t.argmax(axis=1), t变为`[2, 0]`, axis=1 表示**聚合** shape(2, 3) 中的3对应的元素, **将每个数组这一维的元素聚合为1个**, 抹除这一维使得 shape 变为(2,), 也就是说 argmax 会在3对应的维度上找到最大值, 返回最大值的索引. 将 `[[0, 0, 1], [1, 0, 0]]` 变为 `[2, 0]` .
- 这时t就变为标签了.

**最终计算:**
- np.arange(batch_size) 是 `[0, 1]`, t 为 `[2, 0]`, 即每个样本的正确标签.
- `y[[0, 1],[2, 0]]` , 容器的样子为`[x1, x2]`, 取出 y 的第 0 行第 2 列的概率填入 x1, 第 1 行第 0 列的概率填入 x2.
- 最终返回`[x1, x2]`后, 进行后续计算.

**综上: 以上就是交叉熵函数的四种输入情况的处理流程.**
