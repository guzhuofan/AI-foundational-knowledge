## 对于求解数值导数的顺畅理解
**正向逻辑**
1. 首先先明确, 我们求导求的都是一元函数的导数, 哪怕函数是多元函数, 我们也会固定其他变量, 只对其中一个变量求导. **所以后续讨论我们都默认函数是一元函数.**
2. 函数在某点如 $x_0$ 处的导数 $f'(x)$ 是该点的瞬时变化率, 我们可以把导数看作这一点很小区间内的平均变化率. **因为一元函数一点处的导数是这一点的切线斜率, 我们想象在足够小的区间内, 函数曲线和这个切线是重合的, 所以在这段很小的区间内, 导数这个瞬时变化率就等同于平均变化率**.
3. 综上: 当 $dx$ 足够微小时, **小到 $x_0 + dx$ 在这一点的微小区间内 (也就是说 $x_0 + dx$ 时函数曲线也贴在切线上)**. 这时导数乘以 $dx$ (即 $f'(x) \cdot dx$ ) 可近似等于函数值的差分 $\Delta f = f(x+dx) - f(x)$, 这是微分的核心思想.

**反向逻辑**
1. 接着上面的说法, 已知当 $dx$ 足够微小时, 小到 $x_0 + dx$ 在这一点的微小区间内 (也就是说 $x_0 + dx$ 时函数曲线也贴在切线上). 有 $$f'(x) \cdot dx= f(x+dx) - f(x)$$.
2. 那么我们两边同时除以 $dx$, 就有 $$\frac{f(x+dx) - f(x)}{dx} = f'(x)$$. 这时我们就有了一个求解导数的数值方法, 这就是我们计算方法中学习的**数值微分**.
3. 由此我们就可以**根据函数的定义, 顺畅的理解导数数值解的含义和求法了**.
