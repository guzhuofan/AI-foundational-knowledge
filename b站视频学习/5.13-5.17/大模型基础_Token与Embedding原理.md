# 大模型数据流转解析：从 Token 到预测

本笔记主要记录了大模型处理人类语言的最底层数据流转链路，并重点澄清了“词表”与“词嵌入矩阵”这两个极易混淆的核心概念。

## 一、 大模型底层数据流转链路

大模型（如基于 Decoder-only 架构的 GPT 系列）从接收文本到输出预测结果，经历了以下完整的工作流：

1. **现实文本**（例如："我爱人工智能"）
   ↓ *(切分)*
2. **Token**（例如：`["我", "爱", "人工", "智能"]`）
   ↓ *(查词表 Tokenizer)*
3. **索引 ID**（例如：`[120, 45, 998, 342]`）
   ↓ *(查词嵌入矩阵 Embedding)*
4. **静态高维语义向量**（获取每个 ID 对应的独立高维向量，此时向量是静态的，不包含当前上下文信息）
   ↓ *(输入 Transformer 注意力层)*
5. **动态上下文向量**（经过自注意力机制 Self-Attention 计算，每个 Token 的向量吸收了上下文信息，融合为具有全局语境的动态高维向量）
   ↓ *(解码预测 Un-embedding)*
6. **下一个 Token 的概率**（计算词表中所有 Token 成为下一个词的概率，输出概率最高的 Token，并循环该过程）

## 二、 核心概念辨析：词表 vs 词嵌入矩阵

这两个组件在大模型中完全解耦，分工明确：

### 1. 词表（Vocabulary）
* **本质**：是一个静态的哈希表（字典）。
* **作用**：负责 `Token` ↔ `索引 ID` 的双向转换（“字符串”与“整数”的映射）。
* **归属**：属于**分词器（Tokenizer）**的一部分，在数据预处理阶段工作。
* **特点**：**不参与神经网络运算，也不包含任何语义信息**。它就像新华字典的目录，只告诉你“词”在第几行，但不解释“词”的意思。
* **补充认知**：词表的基本单位 `Token` 不一定是一个完整的“词（Word）”，现代大模型通常使用**子词（Subword）**分词法（如 BPE 算法），以解决生僻字和未登录词（OOV）问题。

### 2. 词嵌入矩阵（Embedding Matrix）
* **本质**：是一个巨大的、可训练的浮点数矩阵（形状通常为 `[词表大小, 向量维度]`，例如 `[100000, 4096]`）。
* **作用**：负责 `索引 ID` → `高维向量` 的转换（“整数”与“高维向量”的映射），即 Look-up Table（查找表）。
* **归属**：是**神经网络模型（Model）的真正第一层**。
* **特点**：里面的权重数字是通过海量数据不断反向传播（Backpropagation）训练得来的。
* **语义关系**：**词嵌入矩阵中的向量关系真实地反映了对应词义的关系**。
  * **距离相近**：语义相似的词（如“苹果”和“香蕉”）在高维空间中的距离（如余弦相似度）非常近。
  * **空间平移**：向量的线性运算反映了逻辑关系（例如著名的 `向量(国王) - 向量(男人) + 向量(女人) ≈ 向量(女王)`）。
