# 初识 Pickle

## 1. 作用与优势
*   **核心作用**：**对象序列化 (Object Serialization)**。把内存里复杂的 Python 对象（如字典、列表、NumPy 数组）原封不动地“冻结”保存到硬盘上。
*   **优势 (Why Pickle?)**：
    *   **跳过解析过程**：直接保存对象在内存中的**最终状态**。
    *   **极速恢复**：下次读取时，不需要再重新执行“解压、解析、转换类型、归一化”等耗时步骤，直接将硬盘上的快照加载回堆内存，瞬间可用。

## 2. 局限性 (Critical Limitations)
*   **只存数据，不存逻辑**：Pickle 保存的是**数据状态 (Data)** 和 **引用 (Reference)**，而不是**可执行代码**。
*   **环境依赖**：反序列化（Load）时，当前的 Python 环境必须包含对象所需的类定义和函数定义。
*   **安全性**：永远不要解压（Load）来源不明的 Pickle 文件，因为它可能在反序列化过程中执行恶意代码。

## 3. 基本用法 (API)

```python
import pickle

# 1. 保存 (Dump)
# dataset: 你要保存的那个对象的引用（比如那个巨大的字典）
# f: 默认为打开或创建mnist.pkl这个文件在当前的python工作目录下, 写入方式为wb(代表写入的都是二进制序列), 这个文件用f作为引用
with open('mnist.pkl', 'wb') as f:
    # 把dataset这个对象序列化为二进制后写入到f这个文件中
    pickle.dump(dataset, f)

# 2. 读取 (Load)
# 默认为打开当前python工作目录下的mnist.pkl文件, 以只读二进制的方式打开, f为文件引用
# 反序列化这个文件中的内容为一个对象到堆内存中, 引用赋给dataset
with open('mnist.pkl', 'rb') as f:
    dataset = pickle.load(f)
```
