## P1：从函数到神经网络（~9min）

### 核心叙事线

**符号主义 → 连接主义** 的范式转换

```
符号主义：人类写出精确函数 f(x) = ...
    ↓ 失败（太多问题人类写不出函数）
连接主义：猜一个函数 → 不断调整 → 逼近真实答案
```

### 关键概念链

1. **线性函数**：`y = Wx + B`，W 和 B 是参数
2. **激活函数**：在线性变换外面套一层非线性运算（如 sigmoid、ReLU），让直线"弯"起来
3. **多输入**：每个 x 对应一个 W
4. **套娃**：线性变换 → 激活 → 线性变换 → 激活 → ...
5. **神经网络**：把这种套娃结构画成圆圈连线图 = 输入层 → 隐藏层 → 输出层
6. **前向传播**：从左到右一层层算出结果

### 一句话总结

> 神经网络的本质就是线性变换套激活函数不断套娃。剩下所有乱七八糟的知识，都是为了算出 W 和 B。

## P2：训练神经网络（~11min）

### 核心问题

怎么算出 W 和 B 这些参数？

### 概念链

1. **损失函数（Loss）**：衡量预测值和真实值的差距
   - 均方误差 MSE：`(预测值 - 真实值)²` 的平均
2. **线性回归**：最简单情况可以直接让导数=0求解
3. **梯度下降**：神经网络太复杂没法直接解 → 每次往"让损失变小"的方向调一点参数
   - `W = W - 学习率 × 偏导数`
   - 偏导数 = 损失函数对参数的"敏感度"
4. **链式法则**：逐层求偏导，从右往左传播
5. **反向传播**：从输出层往前，计算每层参数的梯度

### 一句总结

> 前向传播算输出，反向传播算梯度，参数往梯度的反方向调一点 → 这就是神经网络的训练。

## P3：过拟合与正则化（~8min）

### 核心问题

训练数据上表现完美，新数据上拉胯——这就是**过拟合**。

### 对抗过拟合的武器库

| 方法 | 原理 |
|---|---|
| 简化模型 | 减少参数，别用大炮打蚊子 |
| 增加数据 | 数据量够大，复杂模型也相对简单了 |
| 数据增强 | 旋转/翻转/加噪，从旧数据创造新数据 |
| 提前终止 | 差不多就行了，别训练到完美 |
| L1 正则化 | 损失函数 + 参数绝对值之和，抑制参数疯长 |
| L2 正则化 | 损失函数 + 参数平方和，大参数惩罚更狠 |
| Dropout | 训练时随机丢弃一些神经元，防止过度依赖少数参数 |

### 其他训练问题速览

- **梯度消失/爆炸**：网络太深，梯度太小或太大 → 残差网络、归一化
- **收敛慢/震荡**：动量法、RMSprop、Adam 等自适应优化器
- **计算开销大**：Mini-batch，把大数据切小批处理

### 闪客观点

> "深度学习确实像一门玄学"——但每个问题都有对应的解法，只是解法本身又可以展开成一个新世界。

## P4：神经网络 → CNN（~8min）

### 核心改进

**全连接层的问题**：图像 30×30 = 900 个神经元，下一层 1000 个 = 90 万参数，太大！而且把像素铺平丢失了空间关系。

### 卷积运算

```
取 3×3 的小矩阵（卷积核）在图像上滑动 → 对应位置相乘求和 → 得到新的特征图
```

卷积核的值是**训练出来的**，不是人工设计的。

### CNN 结构

```
输入 → 卷积层 → 池化层 → 卷积层 → 池化层 → 全连接层 → 全连接层 → 输出
```

- **卷积层**：提取局部特征，参数量大幅减少
- **池化层**：降维，保留主要特征，减少计算量
- **全连接层**：最后分类

### 矩阵写法

把 `y = Wx + B` 写成矩阵乘法 `Y = W·X + B`：
- 方便公式推导和抽象
- **充分利用 GPU 并行计算**

## P5：词嵌入（~10min）

### 核心问题

怎么把"我爱你"这种文字变成神经网络能算的数字？

### 编码方式演进

| 方式 | 做法 | 缺点 |
|---|---|---|
| 数字编号 | 1="我", 2="你", 3568="地球" | 维度太低，数字本身无意义 |
| One-hot | 词汇表大小的向量，只有一个位置是 1 | 维度太高（10万维），词之间完全独立 |
| **词嵌入** | 维度适中（如 300 维），每个维度是训练出来的特征 | ✅ |

### 关键概念

- **嵌入矩阵**：所有词向量的集合，通过训练得到（如 Word2Vec）
- **潜空间**：词向量所在的高维空间
- **词向量相关性**：用点积或余弦相似度计算
- **神奇现象**：`国王 - 男人 + 女人 ≈ 王后`（向量运算反映语义关系）

## P6：RNN 循环网络（~10min）

### 核心问题

经典神经网络无法处理"先后顺序"——"我打你"和"你打我"输入是一样的。

### RNN 的方案

```
词1 → 神经网络 → 隐藏状态H1 + 输出Y1
                     ↓
词2 + H1 → 神经网络 → 隐藏状态H2 + 输出Y2
                     ↓
词3 + H2 → 神经网络 → ...
```

每个词的隐藏状态传给下一个词，前面信息一路传递。

### RNN 的问题

1. **长期依赖丢失**：传着传着前面的信息就淡了
2. **必须串行计算**：一个词算完才能算下一个，无法并行

→ 改进：LSTM、GRU（缓解但未根治）

## P7：Transformer（~11min）⭐ 核心

### 彻底方案

> 抛弃"按顺序传递信息"，让每个词**同时看到所有其他词**。

### 注意力机制（Attention）— 逐词详解

```
输入：词向量 X1, X2, X3, X4（已加上位置编码）

对每个词：
  Q = Wq × X    （Query：我要查什么）
  K = Wk × X    （Key：我能提供什么）
  V = Wv × X    （Value：我的实际内容）

对词1：
  Q1·K1 → 和自己的相关度
  Q1·K2 → 和词2的相关度
  Q1·K3 → 和词3的相关度
  Q1·K4 → 和词4的相关度

然后用这些相关度作为权重，加权求和所有 V
→ 得到 A1（包含全部上下文信息的词1新向量）
```

每个词都做一遍 → 所有词都获得了"看到了整句话"的新表示。

### 多头注意力（Multi-Head Attention）

不止一组 QKV，而是**多组**——给每个词多个"学习机会"，从不同角度计算相关性。

### Transformer 完整结构（翻译任务）

```
编码器（Encoder）：
  输入 → 词嵌入+位置编码 → 多头注意力 → 残差+归一化 → 前馈网络 → 残差+归一化

解码器（Decoder）：
  输出 → 词嵌入+位置编码 → Masked多头注意力 → 残差+归一化
       → 交叉注意力（Q来自解码器，KV来自编码器）→ 残差+归一化
       → 前馈网络 → 残差+归一化 → 线性层 → Softmax → 预测下一个词
```

### GPT 的本质

> GPT = Transformer 的**解码器部分**，不断根据前面的词预测下一个词。猜着猜着就变成了聊天、写代码、解数学题。

## 💬 今日讨论补充（2026-05-08）

讨论焦点是 P2 的反向传播原理，两个核心问题：

### 一、偏导数的意义：往哪走、走多少

```
∂L/∂w > 0  →  参数增大则 L 增大  →  要让 L 减小，参数该减小
∂L/∂w < 0  →  参数增大则 L 减小  →  要让 L 减小，参数该增大

记忆：偏导为正减参数，偏导为负加参数
      方向永远和偏导符号相反
```

### 二、怎么高效算出所有参数的偏导数

**核心思想**：把偏导数理解为"很小一段区间内的平均变化率"——w 变一点 → 中间变量跟着变 → L 跟着变。由此我们可以根据这个偏导数的理解算出L怎么随着w变化。

**链式法则**：一路乘到底

```
∂L/∂w = ∂L/∂z₃ × ∂z₃/∂z₂ × ∂z₂/∂z₁ × ∂z₁/∂w
         └────── 每一段算 w 对下一层的影响 ──────┘
```

**反向传播为什么快：中间结果复用**

```
笨办法：算 ∂L/∂w₁ 要从头推到 L，算 ∂L/∂w₂ 又要从头推到 L
        → ∂L/∂z₃ 被重复算了 N 次

反向传播：从 L 往回走，∂L/∂z₃ 只算 1 次存在那
          后面每个参数直接用，每次只多乘一步 → 线性复杂度

前向：w → z₁ → z₂ → ... → L    （每层算一遍，产物是 zᵢ）
反向：L → ... → z₂ → z₁ → w    （∂L/∂zᵢ 算一次，后面各层复用）
```

**一句话**：前向唯一目的是算 L；反向唯一目的是算梯度，靠链式法则把 ∂L/∂w 拆成小段乘起来，中间结果共享，不用重复算。

## 💬 今日讨论补充（2026-05-09）

讨论焦点是 P3 的过拟合与正则化，核心问题：**为什么参数过大不好？**

### 一、大权重为什么 = 过拟合

**直觉**：房价预测 `w₁×面积 + w₂×卧室数 + …`，如果 w₁=10000、w₂=1，模型几乎只"看"面积——少数大参数劫持了整个判断，其他参数学到的东西全被淹没了。

**数学**：大权重 → 对输入极度敏感 → 有"灵敏度"去拟合训练数据的每一个噪音点 → 泛化差。小权重没这个灵敏度，只能学大趋势。

**几何**：L2 范数 ‖w‖² 衡量参数空间的"大小"。权重越大，能表示的曲面越曲折——曲折的曲面能穿过所有训练点，但在点之间完全失控。L2 正则化强制用平滑曲面拟合数据。

**一句话**：正则化的本质是"不让任何一个参数独大"，逼模型把判断力分散到所有参数上。

### 二、P3 知识框架（按逻辑线记，不按名字背）

```
问题：过拟合 = 训练好、测试差 = 背答案 ≠ 学规律
根因：模型复杂度 >> 数据量 → 有能力记住噪音

解法四条路线：
  ① 降低记忆容量：简化模型、提前终止
  ② 增加数据难度：增数据、数据增强
  ③ 惩罚大权重：  L1（逼不重要的变0）、L2（逼权重均匀分布）
  ④ 打破依赖关系：Dropout（随机扔神经元，防止共谋）

附带问题：
  梯度消失/爆炸 → 链式法则放大效应 → ReLU/残差/BatchNorm
  收敛慢/震荡   → 峡谷地形来回跳   → 动量/Adam
  计算开销大   → 全量梯度太贵       → Mini-batch
```

### 三、纸质笔记建议

笔记不列清单、建框架：**问题 → 根因 → 四条解法路线 → 附带坑**。L1/L2 的公式细节随时能查，纸上记逻辑线。

## 💬 今日讨论补充 P4（2026-05-09）

讨论焦点是 P4 的 CNN/卷积网络，核心困惑：**全连接层有什么问题？卷积核从哪来？特征图到底是个啥？**

### 一、全连接层处理图像的两个致命缺陷

```
30×30 灰度图 = 900 像素，下一层 1000 神经元
→ 全连接：900×1000 = 90 万个参数
→ 参数量爆炸

× 更致命：把 900 像素拍平成一排 → 丢失了"谁和谁是邻居"的空间关系
  左上角的像素和右下角的像素在拍平后没有任何位置区别
```

### 二、卷积核 = 加了两个约束的全连接层 W

**处理单位从"单个像素"变成"一小块区域"（如 3×3）**

卷积核就是小号的 W，3×3=9 个参数。关键区别不在大小，在**连接模式**：

```
全连接：每个输出神经元连所有输入
  输出[0] = w₀x₀ + w₁x₁ + ... + w₈₉₉x₈₉₉（所有像素）
  输出[1] = 另一组 w₀'x₀ + w₁'x₁ + ... （又是 900 个参数）

卷积层：加了两个约束
  ① 稀疏连接：每个输出只连局部的 9 个输入（90万 → 9）
  ② 权重共享：所有输出位置用同一组 k₀...k₈（参数从 90万 → 10）

输出[0] = k₀x₀ + k₁x₁ + ... + k₈x₈ ← 只看 3×3 局部
输出[1] = k₀x₁ + k₁x₂ + ... + k₈x₉ ← 同样的 k，向右滑一格
```

**卷积核是训练出来的**，和全连接的 W 一样：随机初始化 → 前向传播 → 反向传播 → 梯度下降更新。

### 三、特征图 = 这一层的所有输出神经元

```
30×30 原图
  ↓ 3×3 卷积核扫一遍
28×28 特征图 ← 每个格子是一个输出神经元的值
  ↓ ReLU 激活
28×28 激活图
```

特征图上位置 (3,5) 的值 = 原图 (3,5) 到 (5,7) 这片 3×3 区域被卷积核探测后的结果。

### 四、多通道卷积（层 2 的核为什么是 3×3×6？）

```
层 1 输出：6 张 28×28 特征图（每张检测一种东西：竖边/横边/斜边...）

层 2 一个核的尺寸 = 3×3×6
  → 第三维 6 = 输入通道数（层 1 输出的 6 张图）
  → 一个核同时看 6 张图，6 组的乘加结果汇总成一个值

铁律：核的通道数 = 输入通道数
      核的个数 = 输出通道数
```

### 五、完整 CNN 管线

```
原图 → 卷积层1（检测边）→ 池化（缩小一半）
     → 卷积层2（检测形状：边组合）→ 池化
     → 卷积层3（检测部件：形状组合）
     → ... → 拍平 → 全连接层 → 分类输出

池化：每 2×2 区域取最大值，降维 + 保留主要特征
```

### 六、CNN 和全连接网络的本质区别

| | 全连接 | CNN |
|---|---|---|
| 中间层 | 信息揉成一团，没有空间语义 | 每层特征图有空间含义 |
| 可解释性 | 无法指着一个神经元说"它检测猫耳朵" | 层1 亮的地方=有边，层3 亮的地方=有眼睛 |
| 范式 | 黑箱调参 | "不强求一步到位，每层做该做的事，交给下层组装" |

**这个差异是深度学习从玄学走向可解释性的起点。** 后来 ResNet、Transformer 的可视化研究都建立在这个基础上。

### 七、纸质笔记建议

```
P4 从神经网络到 CNN
▸ 衔接：有网络（P1）+ 有训练方法（P2）+ 有防过拟合武器（P3）
  → 现在把这个框架用到图像识别上

▸ 矩阵写法（钉住）
  Y = W·X + B，一行替代一长串
  好处：① 推导简洁 ② GPU 并行计算基础
  卷积核的 K 也是 W，只是小号+共享版，写法一样

▸ 全连接的问题
  ① 参数爆炸 ② 拍平丢失空间关系
  → 处理单位：单个像素 → 小块区域

▸ 卷积核
  = 小号 W（3×3），训练方式和 W 完全一样
  精妙处：稀疏连接 + 权重共享，90万参数→10个

▸ 特征图
  = 该层所有输出神经元排成二维阵列
  核扫过的地方各得一个值，组成一张新"图"

▸ 多通道
  层2 核尺寸 = 3×3×6（第三维=输入通道数）
  同时看上一层所有图，综合判断

  卷积(边) → 池化 → 卷积(形状) → 池化 → 卷积(部件) → 拍平 → 全连接→分类
  每层做自己层级该做的事

▸ vs 全连接的本质
  FC 中间层没语义，CNN 每层可解释
  这是深度学习可解释性的起点
```

### 八、后续延伸问题（反向传播训练的澄清）

讨论中你追问了"反向传播到底是数值解还是解析解"——这个问题和今天（5/10）的自动微分讨论是同一条线。核心结论：

- **数值微分**：`(L(w+h)-L(w))/h`→ 近似值，慢，误差大
- **反向传播（自动微分）**：每个基础运算的导数公式已知 → 代入链式法则 → 精确值（到机器精度）
- **前向传播的唯一目的**：算损失值 L 和记下中间值（给反向用）
- **反向传播的唯一目的**：从 L 往回走，复用中间偏导数，一次算出所有梯度

## 💬 今日讨论补充 P5（2026-05-10）

讨论焦点是 P5 的词嵌入，核心问题：**词嵌入到底是怎么训练出来的？**

### 一、训练心法

词嵌入不是"设计"出来的，是在完成"猜词任务"的过程中顺便学到的。

类比：你学英语时没人给你发"300维语义说明书"，你通过大量阅读看到"apple"总出现在"eat, fruit, red, tree"旁边，慢慢在脑中形成概念。

### 二、Word2Vec 两种方式

**CBOW（连续词袋）：用周围词猜中间词**
```
输入："我 __ 吃苹果" → 猜中间是"爱"
过程："我""吃""苹果"三个词各查一个300维向量 → 平均 → 预测"爱"
      猜错 → 反向传播 → 调向量 → 反复 → 最终所有词向量编码了语义
```

**Skip-gram（跳字）：用中间词猜周围词**
```
输入："爱" → 猜它周围会出现"我""吃""苹果"
```

本质：词嵌入 = 一张巨大的查找表（词汇量 × 300维），初值随机 → 猜词任务驱动 → 梯度下降训练。

### 三、训练完的效果

- 相似词向量接近：cos("猫","狗") >> cos("猫","花岗岩")
- 向量可以做语义运算：国王 - 男人 + 女人 ≈ 王后，巴黎 - 法国 + 日本 ≈ 东京

### 四、纸质笔记

```
P5 词嵌入 — 把文字变成神经网络能懂的数字

▸ 衔接：有网络结构（P1→P4），但输入一直是数字。
  真实数据是文字，怎么变成数字？

▸ 为什么不能简单编号/One-hot？
  编号：数字大小暗示顺序，"爱"比"你"大？没道理
  One-hot：10万维，任意两词点积=0，"猫"和"狗"=0，"猫"和"花岗岩"=0

▸ 词嵌入的核心思想
  300维稠密向量，每个维度是学出来的语义特征
  相似词靠得近

▸ 词嵌入怎么来的？
  CBOW：给上下文猜中间词 → 猜错→调向量
  本质：查找表（词汇量×300维）→ 随机初始化 → 猜词任务 → 训练

▸ 训练完的效果
  语义运算：国王-男人+女人≈王后
  向量空间里，语义关系=方向

▸ 往后看
  有了词嵌入，RNN（P6）才能处理序列
```

## 💬 今日讨论补充 P6（2026-05-10）

讨论焦点是 P6 的 RNN 循环网络，涵盖：RNN 结构、设计理由、CNN 类比、RNN 问题。

### 一、核心问题

"我打你"和"你打我"的词向量集合一模一样，只是顺序不同。普通神经网络看不出区别 → 需要能处理"顺序"的结构。

### 二、CNN 类比

| | CNN | RNN |
|---|---|---|
| 处理的"结构" | 空间（像素谁挨着谁） | 时间（哪个词先哪个词后） |
| 保留信息的方式 | 卷积核只看局部 | 隐藏状态一路传下去 |
| 权重共享 | 全图共用同一组 K | 所有时间步共用 W_h, W_x |

### 三、RNN 结构

```
输入₁ → 计算 → 输出₁ + 隐藏状态H₁
                ↓ (H₁传给下一步)
输入₂ + H₁ → 计算 → 输出₂ + H₂
                ↓ (H₂传给下一步)
输入₃ + H₂ → 计算 → 输出₃ + H₃ ...

每步同一公式：H_t = tanh(W_h·H_{t-1} + W_x·X_t + B)
```

设计理由：① 处理变长序列，同一套参数反复用 ② 每个输出包含前面所有词的信息 ③ 参数不随序列长度增长

### 四、两大问题

**① 长期依赖消失**：反向传播时梯度沿时间轴回传，传几十步后≈0。类比传话游戏，传50个人后完全走样。

**② 必须串行计算**：必须算完H₁才能算H₂，GPU并行能力用不上。

补救：LSTM（加记忆门/遗忘门）、GRU（简化版），缓解但未根治。

### 五、纸质笔记

```
P6 RNN 循环网络 — 让模型理解"先后顺序"

▸ 衔接：有词嵌入（P5），但"我打你"和"你打我"词一样顺序不同
  → 需要能处理顺序的结构

▸ CNN 类比
  CNN 卷积核扫局部 → 保留空间关系
  RNN 隐藏状态传下去 → 保留时间关系
  都用了权重共享（CNN共享卷积核，RNN共享W_h,W_x）

▸ RNN 结构
  输入₁ → 输出₁ + 隐藏H₁
         ↓
  输入₂ + H₁ → 输出₂ + H₂
         ↓
  输入₃ + H₂ → 输出₃ + H₃ ...
  每步同一公式：H_t = tanh(W_h·H_{t-1} + W_x·X_t + B)
  第三个输出 = 词3 + 词2痕迹 + 词1痕迹

▸ 为什么这样设计？
  ① 变长序列复用同一套参数
  ② 越靠后的词知道越多上下文
  ③ 参数不随序列长度增长

▸ 两大死穴
  ① 长期依赖消失：梯度沿时间回传，几十步后≈0
  ② 必须串行：H₁→H₂→H₃，GPU并行白搭
  补救：LSTM（记忆门）、GRU（简化版），缓解未根治

▸ 往后看
  Transformer（P7）彻底抛弃串行——
  所有词"同时看到所有其他词"（Attention）
```
