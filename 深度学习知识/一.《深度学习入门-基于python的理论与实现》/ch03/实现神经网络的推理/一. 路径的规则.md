# os.path
os.path是Python标准库os模块(包)中的一个子模块(py文件).
它专门用来处理文件路径(Path), 而且它非常智能, 会自动处理不同操作系统(Windows vs Linux/Mac)之间的路径分隔符差异(例如Windows用\\, 而Linux用/)

**在开始之前, 有一个理解需要加深, 也就是我们python要执行一个文件, 那首先要知道这个文件的路径, 也就是说要么是`python 绝对路径`; 要么是已知python的当前工作目录, 在当前工作目录下弄清楚文件的相对路径, 然后执行`python 相对路径`. 总之, 要执行一个文件, 你必须要让python清楚文件在哪.**

## os.path中的常用函数(见到了再更新)
### 一. os.path.abspath(\__file__) (重要!)
**1. 首先解释一下__file__这个变量**
\__file__ 确实是模块对象的一个元数据属性(就像 \__name__ 一样). 
当一个.py文件被加载(无论是直接运行还是被导入)时, Python 解释器会自动给这个模块对象设置__file__属性, 它的值是 **该文件在文件系统中的路径**, 文件系统的路径意思是:
1. 如果你在终端输 `python mnist.py`,  __file__ 就是 `mnist.py`
2. 如果你在终端输 `python ch03/实现神经网络的推理/mnist.py`, __file__ 就是 `ch03/实现神经网络的推理/mnist.py`
3. 如果你在代码里 `import dataset.mnist`, Python 找到了那个文件, __file__ 通常会是那个文件的完整绝对路径

**一句话说, python解释器通过什么路径找到的这个程序, 那么 __file__ 就是这个找到的路径, __file__ 忠实地记录了脚本被加载时所使用的路径字符串.**

**2. os.path.abspath(path)这个函数**
os.path.abspath(path) 实际上只做一件事: **拼接**, 分两种情况:
1. 如果path是一个绝对路径, 那么函数检测到path以盘符开头, 其会直接返回path.
2. 如果path是一个相对路径, 那么**os.path.abspath(path) = os.getcwd() (当前工作目录) + path (你给的字符串)**

**总的来说, 只要文件被正常执行了, 那么os.path.abspath(__file__)就一定能返回这个文件的绝对路径. 这是绝对真理!!! 因为这时候如果用相对路径执行的文件, 说明当前python解释器的工作目录就是在相对路径的父目录中; 如果用绝对路径执行的文件, 那函数就直接返回这个文件的绝对目录了.**

### 二. os.path.dirname(path) (简单!)
这个函数的功能很简单, 他会自动删除当前输入path的最后一个文件, 获取一个路径的目录部分(Directory Name), 也就是去掉文件名, 只保留文件夹路径. **例子:**
输入的path为 `d:\...\dataset\mnist.py`, 它会切掉 `mnist.py`, 返回 `d:\...\dataset`

**所以综上, 我们常见到的os.path.dirname(os.path.abspath(__file__))应该理解为:**
1. 先获取当前执行的py文件的绝对路径, 例如 `d:\...\dataset\mnist.py`
2. 再删除最后一个文件, 得到 `d:\...\dataset`

### 三. os.path.join(path1, path2, ...) (简单!)
这个函数的功能也很简单, 他会自动根据当前操作系统的路径分隔符, 拼接多个路径字符串. **例子:**
输入的path1为 `d:\...\dataset`, path2为 `mnist.py`, 它会返回 `d:\...\dataset\mnist.py`

### 四. os.path.exists(path) (重要!)
os.path.exists(path) 可以理解为一个**探针**. 
- 给它的path是绝对坐标, 那它就探那个坐标是否存在(通过调用操作系统内核API).
- 给它的path是相对坐标, 它就探"脚下", 即当前工作目录中有没有这个相对坐标.
- 它不负责全盘搜索，只负责验证"此时此地"有没有这个东西. 
**例如:**
假设你现在的 CWD 是 `C:\Users\Me` ，你查 `os.path.exists("test.txt")` ，它实际上是去查 `C:\Users\Me\test.txt` 是否存在.

# sys.path
sys.path 是 Python 解释器在导入模块时搜索的路径列表. 当你在 Python 脚本中使用 `import` 语句导入一个模块时, Python 解释器会在 sys.path 中列出的目录中搜索该模块.
**例如:**
假设你现在的 CWD 是 `C:\Users\Me`, 你当前文件 `import dataset.mnist` ，Python 解释器会先在 `C:\Users\Me` 中搜索 `dataset` 文件夹, 找不到再去sys.path 中其他文件夹下搜索.
