# 第三章总结：从感知机到神经网络的跨越

## 1. 章节脉络：自动化与非线性的引入

如果说第二章是“手工搭建电路”，那么第三章就是“迈向自动化工厂”的第一步。作者的讲解逻辑非常连贯：

1.  **痛点引入**：第二章虽然证明了感知机很强，但权重（w, b）都是我们**人工设定**的（比如 XOR 门里的参数是我们凑出来的）。如果网络有 1000 层，人脑怎么凑？
    *   *目标：我们需要一个能自动学习参数的模型——神经网络。*
2.  **激活函数的进化**：
    *   感知机用的是 **阶跃函数 (Step Function)**：硬邦邦的 0 和 1，不可导，无法学习。
    *   神经网络引入 **Sigmoid**：平滑的曲线，处处可导（为梯度下降做准备）。
    *   现代标配 **ReLU**：简单高效，解决梯度消失。
3.  **计算的基石**：如何高效计算？
    *   引入 **多维数组 (NumPy)**。
    *   利用 **矩阵乘法 (np.dot)** 一次性算出整层的输出，告别 `for` 循环。
4.  **实战架构**：搭建一个 3 层神经网络。
    *   输入层 -> 隐藏层1 -> 隐藏层2 -> 输出层。
    *   重点讲解了**信号的传递**（矩阵相乘 + 加偏置 + 激活函数）。
5.  **输出层的设计**：
    *   回归问题用恒等函数。
    *   分类问题用 **Softmax**（将输出转化为概率）。
6.  **推理实战 (MNIST)**：
    *   加载真实数据集（MNIST 手写数字）。
    *   利用预训练好的权重（sample_weight.pkl）进行推理，验证准确率。
    *   引入 **Batch 处理** 加速计算。

## 2. 核心知识点串联

### 2.1 激活函数：灵魂所在
你在 `ch03` 目录下已经有 `sig_step_compare.py` 和 `relu.py`，请结合它们回顾：
*   **非线性的必要性**：这是面试必考题。如果激活函数是线性的（比如 $h(x) = cx$），那么三层网络 $y = c(c(cx)) = c^3x$ 依然等价于一层。**只有引入非线性（Sigmoid/ReLU），多层网络才有意义。**
*   **Sigmoid**: $\frac{1}{1+e^{-x}}$，输出在 (0, 1) 之间，早期常用，现在多用于二分类输出。
*   **ReLU**: $max(0, x)$，正区间无梯度衰减，计算极快，是现在的默认选择。

### 2.2 矩阵乘法的维度魔法
这是新手最容易晕的地方。结合你写的笔记 **《三. numpy中reshape的规则.md》** 和 **《六. NumPy的Axis与广播机制详解.md》**：
*   **规则**：$A \times B$，A 的第 1 维必须等于 B 的第 0 维。
    *   `X` shape: `(2)` (输入)
    *   `W` shape: `(2, 3)` (权重)
    *   `Y` = `X @ W` -> shape `(3)`
*   **reshape**：当你需要改变数组的形状时，用ndarray的reshape方法. 一定要清楚reshape的底层原理, 它只是一个视图(view), 不会改变数组数据的内存布局, 数组的数据在内存中始终是横着排的一行, 甚至可能多个ndarray用同一行数据. reshape只是改变ndarray的视图属性, 所以reshape的时间复杂度是O(1).
*   **广播 (Broadcasting)**：一定要重读你的笔记，特别是“右对齐”和“自动补全”原则，这在加偏置 `b` 时至关重要。

### 2.3 Softmax 与输出
$$y_k = \frac{\exp(a_k)}{\sum_{i=1}^{n} \exp(a_i)}$$
*   **Softmax**：将一堆任意实数（Logits）变成**概率分布**（和为 1，且都在 0~1 之间）。
*   **溢出问题**：代码实现时每个$a_i$需要减去最大值（$a_j$），这样可以防止 $e^{1000}$ 这种天文数字导致 `nan`, 并且最终每个概率的值还不会变, 因为$\exp(-a_j)$可以提出来, 对每个$a_i$都有, 分子分母上下消了结果就不变.
*   **推理时可省略**：因为 Softmax 是单调递增的，如果你只是想知道“哪个数字概率最大”（argmax），不需要算 Softmax，直接看谁的 Logit 最大就行。但在**训练**（算 Loss）时必须算。

### 2.4 Batch 处理 (批处理)
结合 **《五. load_mnist函数详解.md》**：
*   **目的**：利用矩阵运算库（BLAS/LAPACK）对大规模数据的优化，一次算 100 张图比算 100 次 1 张图快得多。
*   **形状变化**：
    *   单张：`X` `(784,)`
    *   Batch：`X` `(100, 784)`
    *   这种维度视角的切换（从向量思维到矩阵思维）是这一章的难点。
