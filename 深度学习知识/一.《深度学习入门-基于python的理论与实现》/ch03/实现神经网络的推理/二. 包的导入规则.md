## 包的导入规则
在本次代码实现中发现dataset的__init__.py文件为空，没有任何代码. 所以对于这种情况的导入有些疑问. 以下是思考结果:
### 核心流程：from dataset.mnist import load_mnist

1. 查找 (Find):
   - Python 扫描 sys.path, 找到了 dataset 文件夹.
   - 因为它包含 __init__.py, Python 认定它是一个包(Package).

2. 加载父包 dataset:
   - 创建对象: 在堆内存中创建一个新的module对象(对应dataset包).
   - 注册: 将该对象注册到 `sys.modules['dataset']` 中
   - 执行初始化: 开辟栈帧执行 `dataset/__init__.py` 
     - 执行结果(栈帧中创建的局部变量)存入dataset对象的__dict__
   - 注: 此时 dataset 对象的__dict__里还没有 mnist

3. 加载子模块dataset.mnist: 
   - 因为在dataset的__dict__中没有找到mnist, 所以Python会继续查找: Python 在 dataset 目录下找到了 mnist.py
   - 创建对象: 在堆内存中创建一个新的module对象(对应dataset.mnist模块)
   - 注册: 将该对象注册到 `sys.modules['dataset.mnist']` 中
   - 执行代码: 开辟栈帧执行 `dataset/mnist.py` 
     - 函数 load_mnist 被定义, 其引用存入 dataset.mnist 对象的__dict__ (key: "load_mnist" )

4. 建立父子关联 (Binding) —— 此前遗漏的关键步骤:   
   - Python自动将子模块对象(dataset.mnist)的引用添加到父包对象(dataset)的__dict__中
   - 结果: 此时 dataset 对象的__dict__中多了一个条目: `key="mnist" , value=<module 'dataset.mnist'>`
   - 这就解释了为什么以后可以用 dataset.mnist来访问它

5. 导入目标符号 (Import Symbol): 
   - Python从dataset对象找到mnist对象, 再从mnist对象的__dict__中查找名为"load_mnist"的对象
   - 找到后，获取其引用

6. 当前命名空间赋值 (Assignment):
   - 回到 mnist_show.py 的执行环境
   - 将刚刚获取的 load_mnist 引用, 赋值给当前命名空间中的变量 load_mnist

**注意:**
如果在__init__中就导入了mnist模块, 那么执行过程会更加清晰.
